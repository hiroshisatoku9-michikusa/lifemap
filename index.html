関係性

ゲーム間のつながり。階層はここから自動計算される。

strong parent: 強い親子関係(実線)。明確に上位→下位の構造的依存。
weak parent: 弱い親子関係(点線)。緩やかな影響、引き継ぎ、変質、派生など、構造ほど強くない繋がり。
階層はどちらの親関係からも自動計算される。

人生の解釈図 — 使い方

このアプリは、あなたが人生の各局面でどんな「ゲーム(問い・目標)」を生きていたかを描き出し、それらが時間とともにどう生まれ、変化し、繋がり合ったかを可視化するためのツールです。

① まずは触ってみる

初めて使うなら、ヘッダーの 「サンプル読込」 ボタンを押してみてください。HIROSHI SATOさん(34歳)の人生マップが読み込まれます。「解釈図」タブを開けば、彼の15歳から34歳までを転換点ごとに辿れます。

※ サンプル読込は既存のデータを上書きします。自分のデータがある場合はまず「エクスポート」で保存してください。

② 4つの基本要素

⏱

転換点(Event)

人生の節目となる出来事や時期。「高校入学」「就職」「結婚」「コロナ襲来」など。解釈図はこの転換点ごとに1フレームずつ表示されます。

○

ゲーム(Game)

その時期にあなたが取り組んでいた問い・目標・関心。「いい大学に入る」「仕事にやりがいを見つける」「いい人生を生きる」など。期間と奥行き(front/mid/back)、達成度(0〜100%)を時系列で記録できます。

↳

関係性(Relation)

ゲーム同士の親子関係。「いい人生を生きる」の下に「いい大学に入る」がある、のような構造を作ります。強い親子(実線)/弱い親子(点線)/関係なしを転換点ごとに切り替え可能。

▭

カード(Card)

ゲームを通じて習得(○+)した能力・知識・人間関係、または活用(↻)した既存カード。「粘り強さ」「銀行業務」「Tさん(友人)」など。進化・分岐の系譜も記録できます。

③ 解釈図の見方

  • フレーム送り: 上部の ◀ ▶ ボタンか左右矢印キーで転換点を移動。各フレームはその時点でアクティブだったゲームの状態を示します
  • 奥行き: ゲームの大きさは奥行き(front=大、mid=中、back=小)。重要度や自覚度の階層を表現します
  • 達成度ゲージ: 各ノード内の電池型ゲージ。色が達成度を示します(灰→赤→黄→緑)
  • 左肩のドット: 前フレームと比較した達成度の変化(青緑=上昇、赤=下降、灰=変化なし)
  • 黄色塗りのノード: その転換点で新しく登場したゲーム
  • 青緑塗りのノード: 奥行きが前進(より重要に)したゲーム
  • 黄色の関係線: 新しく生じた、または強まった親子関係
  • TOPチップ: 上部に表示される「その時の最上位ゲーム」とその達成度

④ ノード操作

  • ホバー: 直系の親・子孫だけが鮮明になり、他は薄くフェード。系譜を瞬時に確認できます
  • ドラッグ&ドロップ: ノードを左右にドラッグして位置を調整。配置はその転換点専用に保存されます
  • クリック: ゲーム編集ダイアログを開く
  • ホバー時のアクションボタン(右側に縦並び):
    • 編集 / 子ゲームを追加(プロンプトで即作成) / カードを追加 / 関係線を引く / 削除
  • 左下のFAB(+): 現在のフレームに新しいトップレベルのゲームを追加

⑤ フローティングカード(下部)

画面下に並ぶカードは、現在の転換点までに獲得してきた全カードを時系列で並べたものです。デフォルトでは重なって名前の一部だけ見え、ホバーすると詳細が浮き上がって表示されます。カードクリックで編集ダイアログが開きます。

  • 黄色枠: その転換点で獲得したカード
  • スポットライト: その転換点で活用中のカード(動的なグラデーション)
  • フェード(半透明): 進化してより新しいカードになった元カード。新カードにホバーすると元カードも再表示されます

⑥ おすすめの作り方

  1. 転換点タブで人生の主要な出来事を時系列に並べる(10〜20個程度)
  2. ゲームタブまたは解釈図のFAB(+)ボタンで、その時々取り組んでいた問いをゲームとして追加
  3. 解釈図でホバー→子ゲーム追加を繰り返して、ゲームの親子構造を組み上げる
  4. 解釈図で各転換点に移動し、ゲームの奥行き・達成度を調整
  5. カードを追加ボタンで、その経験を通じて得たもの(能力・人間関係)を記録
  6. 気がついたら、定期的に エクスポート で JSON をバックアップ

⑦ データの保存とシェア

  • データは自動的にブラウザの localStorage に保存されます(別のブラウザ・別のPCには移動しません)
  • エクスポート: 現在のデータを JSON ファイルとしてダウンロード
  • インポート: JSON を貼り付けて読み込み(古いスキーマも自動マイグレーション)
  • シェア: 別ブラウザの人にこのアプリを使ってほしい時に使う(ヘッダーの「シェア」ボタン)

💡 哲学

このアプリは「正解」を作るためのものではありません。あなたが過去にどんな問いを生きていたかを、今の視点から解釈し直すためのものです。同じ出来事も時間を経て見え方は変わります。何度でも書き直していい、何度でも書き直すことに意味がある、そういうツールです。

このアプリをシェア

このアプリを誰かに使ってほしい時の方法です。

① HTMLファイルを渡す(かんたん)

このページのHTMLファイルそのものをメール/Slack/AirDropなどで送るのが最も簡単です。受け取った人はファイルをダウンロードしてダブルクリックで開くだけ。

※ 各人のデータは各人のブラウザ内に保存されます(共有はされません)

② URLをQRコードで共有

このアプリをサーバー(GitHub Pages、Netlify など)にアップロードして、そのURLを開いた状態でこのボタンを押すと、現在のURLのQRコードが生成されます。

③ 自分のデータを誰かに渡す

自分のデータを他の人に見せたいときは、ヘッダーの エクスポート でJSONを保存して送ってください。受け取った人はアプリを開いて インポート で読み込めます。
